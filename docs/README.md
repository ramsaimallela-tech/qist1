# GitHub Pages (static site)

This folder is a **static HTML** showcase of the AP Grid Quantum Optimiser.

## Enable Pages

1. Push the repo to GitHub (including the `docs/` folder).
2. Repo → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` · Folder: `/docs`
5. Save

Your site will be at:

`https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

## Note

GitHub Pages cannot run Streamlit or call IBM Quantum live.
For the interactive dashboard, use Streamlit Community Cloud (see `/DEPLOY.md`).
